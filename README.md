# תרגול יומי לחיווט מחדש של המח הרגיש

יומן תרגול יומי בעברית: תרגול בוקר, תרגול במהלך היום וסיכום ערב, עם סיכומים שבועיים, חודשיים ושנתיים וגרפי מגמה.

**לאפליקציה:** https://ruthielax-pixel.github.io/HSP-Rewire-daily/

## מה יש באפליקציה

- **יומן יומי** – הכרת תודה, מנטרות, תרגיל חמלה עצמית, משפט עוגן, ספירת זיהויים, כלי עצירה, החלפת מחשבה, טריגרים, מערך תמיכה ודירוגים.
- **דאשבורד** – המשפט העוגן של היום, רצף ימים, והתקדמות לפי השבוע (ראשון–שבת), החודש והשנה הקלנדריים.
- **סיכומים** – שבועי, חודשי ושנתי, עם גרפים ושאלות לרפלקציה.
- **מגמות יומיות** – גרפי קו ל-14/30/90 ימים עם ממוצע נע של 7 ימים, והטריגרים השכיחים.
- **טיוטה** – מה שמוקלד ביומן נזכר גם אם האפליקציה נסגרת. רק "שמור יומי" שומר ביומן. המשפט העוגן נשמר מיד כשבוחרים אותו.
- **גיבוי ושחזור** לקובץ JSON, וייצוא CSV של השבוע.
- **אפליקציה בטלפון** – אפשר להתקין למסך הבית, והיא עובדת גם בלי אינטרנט.

## התקנה בטלפון

- **אנדרואיד (כרום):** כפתור "התקנה" בדאשבורד, או בתפריט ⋮ ← "התקנת האפליקציה" / "הוספה למסך הבית".
- **אייפון (ספארי):** כפתור השיתוף ← "הוסף למסך הבית".

## איפה הנתונים נשמרים

הכול נשמר **רק בדפדפן של המכשיר** (localStorage). אין שרת ואין סנכרון.

- כדאי לשמור קובץ גיבוי מהדאשבורד מדי פעם. אחרי שבוע בלי גיבוי מופיעה תזכורת.
- כדי להעביר נתונים למכשיר אחר: שומרים גיבוי במכשיר אחד ומשחזרים במכשיר השני.
- באייפון, האפליקציה שהותקנה למסך הבית שומרת נתונים בנפרד מספארי.
- ניקוי נתוני האתר בדפדפן מוחק את כל היומנים.

## מבנה הקבצים

| קובץ | מה הוא |
|---|---|
| `index.html` | כל האפליקציה: HTML, CSS ו-JavaScript בקובץ אחד |
| `sw.js` | Service worker – עבודה בלי אינטרנט ועדכון גרסאות |
| `manifest.webmanifest` | הגדרות ההתקנה כאפליקציה (שם, צבעים, אייקונים) |
| `icons/` | אייקונים לאפליקציה |

## עדכון האפליקציה

1. משנים את הקבצים (או פותחים Pull Request ומאשרים Merge).
2. **מעלים את מספר הגרסה** בשורה `const VERSION = 'v4';` בתחילת `sw.js` (למשל ל-`v5`). בלי זה, מכשירים שכבר התקינו את האפליקציה עלולים להמשיך להציג את הגרסה הקודמת.
3. GitHub Pages מעדכן את האתר תוך דקה-שלוש (אפשר לראות בלשונית Actions).
4. בטלפון: סוגרים את האפליקציה לגמרי ופותחים שוב.

כדי לבדוק מקומית, פותחים את `index.html` בדפדפן. התקנה ועבודה בלי אינטרנט עובדות רק מכתובת https (או `localhost`).
